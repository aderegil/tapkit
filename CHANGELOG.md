# Changelog

## tap-teams-message 1.0.0 (2026)

First release.

- Writes formatted Teams messages for chats, group chats, meeting chats and channels.
- Builds one HTML page: preview, Data panel with typed fields (dates, times, numbers, choices, images), Settings panel, Edit with a formatting toolbar, Copy for Teams.
- Download the page with your changes, or save a recipe so Claude writes the next message the same way.
- Page in English or Spanish.
